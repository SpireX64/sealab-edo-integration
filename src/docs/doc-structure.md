# Структура папки документа

Каждый документ (подтип ЭТрН, ЭТрН и т.д.) располагается в собственной папке внутри `docs/{тип}/{номер}/`.

## Структура папки

```
docs/{тип}/{номер}/
├── index.ts                         # Публичное API: типы + енумы + конструктор документа
├── doc.ts                           # Тип документа + конструктор (таб-5.2)
├── consts.ts                        # Енумы + их format-мапперы
├── types.ts                         # Общие типы без номера таблицы (НЕ из data/)
└── data/                            # Файлы таблиц спецификации
    ├── {таб}-{Имя}.ts               # Тип + format-функция для каждой таблицы
    └── ...
```

## Назначение файлов

### `index.ts` — Публичное API
- Реэкспортирует **только**:
  - Конструктор документа (`DocumentXxxxx`)
  - Тип документа (`TDocumentXxxxx`)
  - Все енумы из `consts.ts`
  - Все типы (T*) из `types.ts` и `data/*.ts`
- **НЕ** реэкспортирует:
  - Функции форматирования (`format*`) — это внутренние служебные функции
  - Приватные константы/утилиты (regexp, валидаторы)

### `doc.ts` — Конструктор документа
- Тип документа (`TDocumentXxxxx`, расширяет корневой тип из `data/`)
- Конструктор `DocumentXxxxx`, использующий `Document({type, subtype}, payload)`

### `consts.ts` — Енумы и мапперы
- Все `enum`-ы документа
- `format*`-мапперы для строковых енумов (switch → русский текст)
- НЕ содержит типы — только значения

### `types.ts` — Общие типы
- Типы без номера таблицы спецификации
- Агрегатные типы (например `TAddress` из нескольких адресных типов)
- **Не импортирует** из `data/` (избегает циклических зависимостей)
- Может импортировать из `../../helpers` и `./consts`
- Типы, которым нужны импорты из `data/` (например `TTransportCustomerInfo` с зависимостью от `TPartyDetails`), выносятся в `data/` с номером таблицы

### `data/{таб}-{Имя}.ts` — Таблицы спецификации
- Один файл на таблицу из спецификации
- Имя: `{номерТаблицы}-{ИмяТипа}.ts` (например `5.9-CargoDescription.ts`)
- **Каждый файл, даже если в нём нет специфичных полей, должен иметь номер таблицы**
- Содержит:
  1. Импорты из `../../../../helpers`, `../../../shared` (для `TODO`), `../types`, `../consts`, соседних `./`
  2. Тип (`export type T*`)
  3. Функцию форматирования (`export function format*`)

## Приватные детали
- Регулярные выражения, валидаторы, вспомогательные константы, относящиеся только к данному документу, остаются **без `export`** в том файле, где используются
- Они не предназначены для переиспользования другими документами

## Правила импортов

| Откуда | Куда | Путь |
|---|---|---|
| `data/*.ts` | `helpers.ts` | `../../../../helpers` |
| `data/*.ts` | `shared.ts` | `../../../shared` |
| `data/*.ts` | `types.ts` | `../types` |
| `data/*.ts` | `consts.ts` | `../consts` |
| `data/*.ts` | соседний `data/X.ts` | `./X` |
| `types.ts` | `helpers.ts` | `../../../helpers` |
| `types.ts` | `consts.ts` | `./consts` |
| `doc.ts` | `data/*.ts` | `./data/X` |
| `doc.ts` | `shared.ts` | `../../shared` |
| `doc.ts` | `etrn/consts.ts` | `../consts` |
| `index.ts` | всё | `./doc`, `./consts`, `./types`, `./data/X` |
