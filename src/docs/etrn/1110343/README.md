# Т7 ЭТрН — переадресовка, КНД 1110343

## Разрешённое исключение для `СодИнфПА/@ВидДост`

По прямому решению заказчика от 08.09.2026 применяется только значение таблицы 9.4 приложения № 1 к приказу ФНС России от 09.12.2021 № ЕД-7-26/1065@:

`Электронное уведомление перевозчика о переадресовке`

Оно экспортируется как `ETRN1110343.READDRESSING_NOTIFICATION_DELIVERY_METHOD`. Кавычки и пробелы по краям не входят в значение. `notificationDeliveryMethod` должен точно совпадать с константой; сокращённые и произвольные значения отклоняются. Форматтер записывает константу без обрезки.

**Известное ожидаемое несоответствие исходной XSD:** строка содержит 51 символ, а `ON_TRNPEREADR_1_973_03_05_01_01.xsd` разрешает для `ВидДост` максимум 50. Исходная схема не изменяется. Сформированный XML поэтому не проходит эту проверку оригинальной XSD; успешный unit-тест формирования XML не означает успешную XSD-валидацию или приём документа оператором.

Источник текста и схемы: [официальный архив приложения № 1 ФНС](https://www.nalog.gov.ru/html/sites/www.new.nalog.ru/files/related_activities/el_doc/pril1_fns1065_251224.zip), [страница приказа](https://www.nalog.gov.ru/rn77/related_activities/el_doc/el_bus_entities/11766120/).

Исключение относится исключительно к `ВидДост`. Требования к основанию переадресовки, подписи, участникам, адресу и остальным полям не изменены.
