# saby-tms-client

Типобезопасный клиент для работы с электронными перевозочными документами (ЭПД)
через JSON-RPC API СБИС Тензор.

Поддерживает:
- документы **ЭТрН** / **ЭЗЗ** / **ЭПЛ** (генерация, запись, действия, статусы);
- саб-клиенты **сотрудников**, **транспортных средств**, **подписания** (Госключ / МЧД / доверие).

---

## Установка

Пакет распространяется из GitLab. Есть два способа установки.

### Способ 1. Git-зависимость (проще для старта)

По SSH:

```bash
npm install git+ssh://git@gitlab.dev-seaportal.ru/development/saby-tms-client.git#dev
```

По HTTPS:

```bash
npm install git+https://gitlab.dev-seaportal.ru/development/saby-tms-client.git#dev
```

После установки npm автоматически выполнит сборку пакета, поэтому вручную собирать ничего не нужно.
